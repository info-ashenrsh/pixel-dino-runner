# 🦖 Pixel Dino Runner

A modern browser game inspired by the classic offline dinosaur game.

## Features

- Pure HTML5, CSS3 & JavaScript
- No libraries
- Original pixel art
- Multiple levels
- Flying enemies
- Coins
- Power-ups
- Day & Night cycle
- Dynamic weather
- High Score saving
- Mobile support
- Responsive design
- 60 FPS gameplay

---

## Controls

### Desktop

- Space → Jump
- ↑ → Jump
- ↓ → Duck
- P → Pause
- R → Restart

### Mobile

- Tap → Jump
- Swipe Down → Duck

---

## Installation

Clone the repository

```bash
git clone https://github.com/info-ashenrsh/pixel-dino-runner.git
```

Open

```
index.html
```

or run

```bash
python -m http.server
```
